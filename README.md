# Obey Kinchi Trading Bot

A modern web app for trading with the Deriv API.

- 💰 Live account balance
- 📈 Volatility Index trading
- ⚙️ Stake, Stop Loss and Take Profit settings
- 📊 Trade statistics
- 📜 Trade history
- 🌙 Modern dark theme
